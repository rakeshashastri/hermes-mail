Hermes Mail

Hermes Mail is a personal, single-user tool owned by Rakesha Shastri. It reads (read-only) one Gmail mailbox, which contains mail the owner has chosen to forward to it, and files the financial details into the owner's own private, local database on their own computer.

It cannot send, delete or modify email. It requests only the Gmail read-only permission (gmail.readonly). It is not offered to the public and has no other users.
